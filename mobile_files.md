# Файлы, необходимые для работы мобильного интерфейса

Этот документ содержит список файлов, которые являются неотъемлемой частью мобильного клиентского приложения Volleyball Scoreboard.

## Структура файлов

### 1. HTML

*   `mobile.html`
    *   **Описание**: Основная и единственная HTML-страница для мобильного интерфейса. Содержит всю разметку для вкладок, модальных окон и элементов управления.

### 2. JavaScript

*   `js/mobile.js`
    *   **Описание**: Главный файл с логикой мобильного приложения. Отвечает за аутентификацию, управление состоянием, переключение вкладок, взаимодействие с API и обработку всех пользовательских действий.
*   `js/templates_visual_mobile.js`
    *   **Описание**: Скрипт для визуального редактора шаблонов, адаптированный для мобильной версии. Загружается и инициализируется при открытии вкладки "Шаблоны".
*   `js/db.js` (предполагаемое имя)
    *   **Описание**: Модуль для работы с базой данных (Firebase/PocketBase). Предоставляет унифицированный API для операций CRUD и подписок на изменения.
*   `js/auth.js` (предполагаемое имя)
    *   **Описание**: Модуль для управления аутентификацией пользователей. Обрабатывает вход, выход и проверку прав доступа.
*   `js/db-config.js` (предполагаемое имя)
    *   **Описание**: Конфигурационный файл, содержащий URL и другие параметры для подключения к провайдеру данных.

### 3. CSS

*   `css/mobile.css` (предполагаемое имя)
    *   **Описание**: Таблица стилей, определяющая внешний вид мобильного приложения, включая адаптивность, цветовые схемы (темы) и стили для всех компонентов.

### 4. Service Worker
*   `sw.js`
    *   **Описание**: Service Worker для кеширования статических ресурсов и обеспечения базовой функциональности в офлайн-режиме.
