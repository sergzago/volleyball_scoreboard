# Volleyball Scoreboard — Android-приложение (WebView)

Нативная обёртка для мобильной веб-версии: `Activity` с `WebView`, который открывает
страницу табло, плюс **компактную кнопку «Настройки» (иконка-шестерёнка) в правом
верхнем углу**, где задаётся адрес страницы, с которой стартует приложение.

Сборка APK здесь — единственная в этом репозитории (в веб-части проекта сборки нет:
`docker-compose.mobile.yml` просто раздаёт статику через nginx).

## Как это работает

| Место | Назначение |
|---|---|
| `MainActivity.kt` | WebView на весь экран, кнопка «Настройки», работа с сохранённым адресом |
| `res/values/strings.xml` → `default_start_url` | **адрес по умолчанию**: `https://zago.my.to/sb/mobile.html` |
| `SharedPreferences` (`vb_webview_prefs`, ключ `start_url`) | адрес, заданный пользователем |
| `res/layout/activity_main.xml` | WebView + прогресс-бар + экран ошибки + кнопка «Настройки» |
| `res/layout/dialog_settings.xml` | диалог ввода адреса |

Правила определения стартового адреса:

1. если пользователь задал адрес — открывается он;
2. если адрес **не задан, пустой или некорректный** — открывается адрес по умолчанию;
3. в диалоге настроек поле пустое = «старт со страницы по умолчанию» (адрес виден
   в подсказке поля), кнопка **«По умолчанию»** сбрасывает сохранённое значение;
4. адрес без схемы дополняется: `zago.my.to/sb/mobile.html` → `https://zago.my.to/sb/mobile.html`;
5. принимаются только `http://` и `https://` — иначе поле подсветится ошибкой и
   диалог не закроется.

## Что ещё умеет обёртка

- **Навигация внутри приложения**: ссылки на сайт (`http/https`, тот же хост)
  открываются в WebView, поэтому работают относительные ссылки `sb.html`,
  `tablo.html`, `results.html` и т.п.; ссылки на **чужие домены** открываются
  во внешнем браузере; внешние схемы (`tel:`, `mailto:`, `intent:`, `market:`)
  передаются системе.
- **Вкладка «Ссылки»** (`div#pageLinks` мобильной страницы): все её ссылки
  открываются **во внешнем браузере** — после каждой загрузки страницы в неё
  инъецируется скрипт, который перехватывает клик и вызывает JS-мост
  `VBLinkBridge` (`addJavascriptInterface`).
- **Кнопка «Назад»** (и жест «Назад») — диалог «Вы хотите выйти из
  приложения?»; по «Да» приложение закрывается, история страниц не откатывается.
- **Экран ошибки** при недоступности страницы с кнопкой «Повторить» и подсказкой
  про «Настройки».
- **Скриншот-состояние** сохраняется при смене конфигурации/пересоздании
  (`saveState`/`restoreState`), `configChanges` не даёт перезагружать страницу при повороте.
- **Файловый ввод**: `<input type="file">` (загрузка логотипа в визуальном
  редакторе шаблонов) открывает системный выбор файла.
- **JS/cookies/localStorage** включены — иначе мобильный интерфейс не работает
  (приложение использует `localStorage` для темы и токенов входа).

## Что нужно для сборки

| Компонент | Версия / путь (эта машина) |
|---|---|
| JDK | 21 (`/home/zago/jdk/jdk-21.0.2`); JDK 25 из системы для Android Gradle Plugin не подходит |
| Android SDK | `/home/zago/Android/Sdk` (platforms: android-34/35, build-tools 35.0.0) — путь прописан в `local.properties` |
| Gradle | 8.14.2 (подтягивается wrapper'ом; уже распакованная копия — `/tmp/gradle-8.14.2`) |
| AGP / Kotlin | 8.7.3 / 2.2.0 |
| minSdk / targetSdk / compileSdk | 26 / 34 / 35 |

### Сборка из Android Studio

1. `File → Open` → каталог `android-webview`;
2. дождаться Sync (Studio сама скачает Gradle 8.14.2 и зависимости);
3. `Build → Build Bundle(s)/APK(s) → Build APK(s)`, либо `Run` на подключённом устройстве.

### Сборка из командной строки

```bash
cd android-webview
export JAVA_HOME=/home/zago/jdk/jdk-21.0.2        # JDK 17–21, не 25
./gradlew assembleDebug                            # первый запуск скачает Gradle 8.14.2
# → app/build/outputs/apk/debug/vbscore.apk
```

Без wrapper (уже распакованным Gradle):

```bash
JAVA_HOME=/home/zago/jdk/jdk-21.0.2 /tmp/gradle-8.14.2/bin/gradle --no-daemon assembleDebug
```

Установка на устройство (включить «Отладка по USB»):

```bash
/home/zago/Android/Sdk/platform-tools/adb install -r app/build/outputs/apk/debug/vbscore.apk
```

### Release-сборка (для обычных пользователей)

```bash
cd android-webview
export JAVA_HOME=/home/zago/jdk/jdk-21.0.2
./gradlew assembleRelease
# → app/build/outputs/apk/release/vbscore.apk  (подписан, версия 1.0.3)
```

Release-сборка подписана ключом `app/release.keystore` (alias `vbscore`),
реквизиты подписи — в `app/keystore.properties`. Оба файла добавлены в
`.gitignore` и **не должны попадать в репозиторий**. В release нет суффиксов:
`applicationId` = `com.sbmobile`, `versionName` = `1.0.3`
(это отдельное приложение рядом с debug-копией, у которой applicationId с
суффиксом `.debug`).

> ⚠️ Сделайте резервную копию `app/release.keystore` и пароля из
> `app/keystore.properties`: без них невозможно выпустить обновление,
> которое установится поверх уже стоящего приложения — Android требует
> совпадения подписи.

## Настройки, важные для эксплуатации

- **Адрес по умолчанию** меняется в одном месте — `app/src/main/res/values/strings.xml`
  (`default_start_url`), после чего нужна пересборка APK (значение запекается в приложение).
- **http-адреса разрешены**: `android:usesCleartextTraffic="true"` в манифесте — чтобы
  можно было указать, например, `http://192.168.1.10:8080/sb/mobile.html` в сети зала.
  Если приложение всегда работает по https, флаг можно убрать.
- **targetSdk 34** выбран специально: система сама отступает контент от статус-бара,
  поэтому шапка страницы и кнопка «Настройки» не перекрываются системными панелями.
  При переходе на `targetSdk 35` нужно либо оставить edge-to-edge и учитывать
  `env(safe-area-inset-*)` на самой странице (сейчас в `css/mobile.css` есть только
  `env(safe-area-inset-bottom)`), либо сдвигать WebView вниз программно.
- **minSdk 26** (Android 8.0+): используется adaptive-иконка без PNG — foreground
  это `drawable-nodpi/b0.webp` (фото мяча из корня репозитория, inset 18dp под
  safe zone), фон — цвет `ic_launcher_background`. Для Android 7
  пришлось бы добавить растровые иконки в `mipmap-*`.
- Кнопка «Настройки» — полупрозрачная плашка поверх страницы в правом верхнем углу.
  Чтобы она не перекрывала `db-provider-badge` в шапке `mobile.html`, приложение
  инъецирует после загрузки стиль, сдвигающий бейдж влево от правого края
  (в браузере бейдж остаётся на месте).
  Кнопку также можно сдвинуть (`@dimen/settings_button_margin`), убрать в нативное
  меню (ActionBar/Toolbar) или, наоборот, вызывать диалог из самой страницы через
  `addJavascriptInterface` (JS-мост).
- Приложение добавляет к `User-Agent` суффикс `VolleyballWebView/1.0.3` — при
  необходимости по нему можно отличить нативное приложение от браузера.

## Проверка сборки

- `./gradlew assembleDebug` / `assembleRelease` — сборка APK;
- установка на эмулятор и запуск (проверяется, что страница загружается, кнопка
  «Настройки» открывает диалог, пустое поле откатывается на адрес по умолчанию);
- лог приложения: `adb logcat --pid=$(adb shell pidof com.sbmobile.debug)`.
